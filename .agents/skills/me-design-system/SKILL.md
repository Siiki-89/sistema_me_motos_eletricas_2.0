# Interface ME
Consultar docs/brainstorming.md e o fluxo do módulo em discussão. Ainda não há identidade visual ou biblioteca aprovada.
Definir tokens e padrões em docs/design-system.md quando autorizado; não inventar marca, paleta ou regras operacionais.
Priorizar leitura de saldos, identificação inequívoca, tarefas frequentes com poucos passos e prevenção de erros.
Especificar estados vazio, carregando, erro, sucesso e indisponível; rótulos, foco visível, teclado, contraste e feedback que não dependa só de cor.
Planejar filtros e paginação conforme volume estimado; preservar contexto após editar/cancelar.
Usar frontend-design para direção visual e web-design-guidelines para revisão técnica, sem duplicar suas instruções.
Usar fontes/assets locais para offline. Validar com Agent Browser e dados sintéticos quando houver frontend; não alegar inspeção visual não executada.
